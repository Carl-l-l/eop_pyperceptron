# EOP - PyPerceptron
Repository for my EOP project, consisting of an analysis of the Perceptron algorithm and its implementation in Python.

## Installation
To install the required packages, run the following command:

```bash
pip install -r requirements.txt
```
This will install all the necessary packages listed in the `requirements.txt` file.


## Usage
This repository is designed to follow the structure of the EOP.
All is written in Jupyter Notebooks, which are located in the `chapters` folder.
The implementation of the Perceptron algorithm is located in the `py_perceptron` folder.
The `models` folder contains the saved pickle files of the models, to be used in the notebooks.
The `data` folder contains the datasets used in the notebooks. Note that the datasets are not included in the repository, reach out to me if you need them.
